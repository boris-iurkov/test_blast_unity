# Тестовое задание "Blast"

### Приложение разделено на 4 части:
- **Core** - содержит единственный класс GameEntry, входная точка игры, сюда устанавливаются ссылки на основные модули и настройки (имеет доступ ко всем другим частям приложения).
- **Controller** - реализует взаимодействие между Model и View; содержит основной класс GameController, который в свою очередь содержит вспомогательные контроллеры для бустеров, шаффла, визуала, взаимодействия с тайлами и окончанием игры (имеет доступ к Model и View).
- **Model** - содержит логику игрового поля, тайлов ходов и очков (не имеет доступа к другим частям приложения).
- **View** - содержит классы для отображения игрового поля, панелей ходов, очков, бустеров, а также для попапа окончания игры (имеет доступ только к Model).

### Логика начисления очков:
- для обычной группы тайлов - (X-1)*10 очков за тайл, где X - размер группы.
- для группы, уничтоженной супер тайлом - 20 очков за тайл.
- для группы, уничтоженной бустером бомбой - 20 очков за тайл.

### Комментарии:
- в приложении многие настройки вынесены в отдельные конфиги - GameConfig (общие настройки), FieldConfig (настройки размеров поля и тайлов), EndGamePopupConfig (настройки попапа окончания игры), а также настройки анимации в папке Assets/Configs/Animation.
- настроек для логики начисления очков нет, можно только поменять целевое кол-во очков в GameConfig.
- cцена для запуска: Assets -> Scenes -> MainScene
